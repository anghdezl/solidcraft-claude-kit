# Glosario

| Sigla / término | Significado |
|---|---|
| 3MF | Formato de proyecto 3D que admite varias piezas, cada una con su filamento |
| ACE | Anycubic Color Engine: caja multimaterial de 4 ranuras |
| Arachne | Generador de paredes de ancho variable del laminador |
| CAD | Diseño asistido por ordenador |
| CLI | Programa que se maneja por línea de comandos |
| Demonio / flag | Programa en segundo plano / fichero señal (`flag.stop`…) que el demonio atiende y borra |
| Ejecutor | Programa del PC que procesa trabajos JSON de SolidCraft (`54`) |
| FDM | Impresión por deposición de filamento fundido |
| G-code | Instrucciones que ejecuta la impresora |
| Hash (SHA-256) | Huella digital de un fichero; el demonio de órdenes solo ejecuta scripts autorizados por hash (`52`) |
| Loft | Operación CAD que une secciones en un sólido (`54`) |
| M600 | Código G de pausa para cambio manual de filamento |
| MCP | Model Context Protocol: conecta herramientas externas a Claude (`52`) |
| Print-in-place | Pieza con partes móviles que se imprime ya montada |
| STEP | Formato CAD de sólidos exactos |
| STL | Formato 3D de superficie por triángulos |
| SVG | Formato de imagen vectorial |
| Z-offset | Ajuste fino de la distancia entre boquilla y cama |
| clr | Holgura de referencia de los diseños, en mm (`53`) |
| MSIX | Formato de paquete de Windows; la app se ejecuta aislada y su configuración queda en una ruta virtualizada (`52`) |
| winget | Gestor de paquetes de Windows (`winget install ...`) |
| UAC | Control de cuentas de usuario: el aviso de Windows al instalar programas |
| SmartScreen | Filtro de Windows que avisa ante instaladores sin firmar |
| MSI | Formato de instalador de Windows |
