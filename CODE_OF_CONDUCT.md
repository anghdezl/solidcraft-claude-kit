# Código de conducta

Este proyecto sigue el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/), que se aplica como referencia completa.

En resumen:
- Trata a las personas con respeto, sea cual sea su experiencia, origen o identidad.
- Critica ideas y código, no personas.
- No se admite acoso, insultos, ataques personales ni publicar datos privados ajenos.
- Se espera que las críticas sean concretas y útiles; las respuestas, en el mismo tono.

**Aplicación:** el titular del repositorio puede editar o eliminar comentarios, issues y PR que incumplan estas normas y bloquear a quien persista. Para reportar una conducta, usa los avisos privados de GitHub del repositorio o la opción *Report content* de GitHub.
